原型说明

微信小程序风格的高保真交互原型，单文件 HTML 实现，可用浏览器直接打开、点击体验。

已实现的演示流程

  • 首页浏览信息 → 查看详情
  • 首页「发布寻物 / 发布招领」→ 填写表单 → 发布成功
  • 首页搜索框 → 输入关键词（可试「校园卡」「钥匙」）→ 查看搜索结果 → 详情
  • 「我的发布」→ 修改信息状态 / 编辑 / 删除

  • 首页（信息列表 + 筛选）
  • 发布信息页
  • 发布成功页
  • 搜索页（含搜索结果）
  • 信息详情页
