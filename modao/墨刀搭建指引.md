# 墨刀搭建指引 · 校园失物招领小程序原型

本文件夹的 7 张 PNG 就是做好的原型界面（2 倍图，750 宽），把它们导入墨刀、按下面的坐标加热区，就能得到一份可点击、可分享的在线原型。

## 二、墨刀操作步骤

1. 打开 <https://modao.cc>，注册 / 登录（微信扫码即可）。
2. 「新建项目」→ 类型选**手机** / 自定义尺寸，页面尺寸填 **375 × 720**；发布页那屏把页面往下拉高到 **940**。
3. 按上表顺序新建 7 个页面并命名（首页 / 搜索 / 搜索结果 / 详情 / 发布 / 发布成功 / 我的发布），每页拖入对应图片，铺到 (0, 0)。
4. 每页加**热区**：从左侧组件面板拖入「链接区域」（热区），按第三节表格填位置、大小，再在右侧「添加交互 → 跳转到页面」里选目标页。
5. 右上角「预览」自测一遍三条流程，最后「分享」→ 复制**原型分享链接**（见第四节）。

## 四、最省事的「最小热区集」（够作业演示三条流程）

时间紧的话，只做这 7 个热区就能把作业要求的三条流程全部走通：

1. 首页：搜索框 → 搜索页
2. 首页：信息卡片 ① → 详情页（流程一：查看信息 → 查看详情）
3. 首页：发布寻物 → 发布页
4. 发布页：蓝色「发布」按钮 → 发布成功页（流程二：发布信息 → 发布成功）
5. 搜索页：热词「校园卡」→ 搜索结果页
6. 搜索结果页：结果卡片 ① → 详情页（流程三：搜索物品 → 查看搜索结果）
7. 各页返回「‹」/「取消」/底部 tab → 回首页或对应页

## 五、拿到分享链接

1. 右上角「分享」→ 选「原型分享链接」→ 复制短链（形如 `https://modao.cc/app/xxxxxxxx`）；
2. 分享设置里建议勾选「允许查看者直接打开原型」（不要设密码）；
3. 把链接填到博客 2.1 节的「墨刀在线原型链接」处即可（也可以直接发我，我帮你填进 blog.md）。
